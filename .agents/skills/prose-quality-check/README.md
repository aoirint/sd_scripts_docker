# prose-quality-check

## Overview

Review explanatory prose for readable structure, self-contained context, and preserved nuance.
Balance section, paragraph, sentence, and list size without fixed length limits.
Remove unnecessary time dependencies and make useful time boundaries explicit in durable documents.
Omit redundant qualifiers and unintended differences between parallel statements
while retaining distinctions readers need.
